# Associate / entry-level skills checklist

Things hiring managers often want to see mentioned (honestly, at foundation level) for junior cyber / security support roles:

- [x] Microsoft Entra ID fundamentals
- [x] Microsoft 365 security basics
- [x] MFA and Conditional Access concepts
- [x] IAM / least privilege
- [x] Active Directory fundamentals (hybrid awareness)
- [x] Microsoft Defender concepts
- [x] Intune / endpoint basics
- [x] Networking fundamentals (TCP/IP, DNS, VPN)
- [x] SIEM / monitoring awareness
- [x] Incident response basics
- [x] MITRE ATT&CK awareness
- [x] Windows + basic PowerShell
- [x] Vulnerability assessment lab practice (Nmap / Kali)

## How to talk about this in applications

Use phrases like:

- “Foundational knowledge of…”
- “Familiar with concepts such as…”
- “Lab practice in…”

Avoid claiming production admin experience unless you have it.
