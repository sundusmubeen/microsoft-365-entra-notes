# Microsoft 365 & Entra ID Notes

Study notes for **entry / associate-level** cyber and IT security roles. Recruiters often look for familiarity with Microsoft identity and M365 security — this repo captures those basics in plain language.

## Why this matters for junior roles

Many SOC, security support, and identity-support jobs expect you to recognise:

- Microsoft Entra ID (formerly Azure AD)
- Microsoft 365 admin / security concepts
- MFA, Conditional Access, and least-privilege access
- Basic Defender / endpoint ideas
