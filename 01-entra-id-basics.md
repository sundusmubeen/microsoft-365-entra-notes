# Entra ID basics (entry level)

Microsoft Entra ID is the cloud identity platform used with Microsoft 365 and Azure. Junior cyber roles often need to understand how people get access — and how that access is controlled.

## Core ideas

| Concept | Why it matters |
| --- | --- |
| Users and groups | Access is usually granted via groups, not one-by-one |
| MFA | Extra proof at sign-in; reduces password-only risk |
| Conditional Access | Rules like “require MFA off-network” or block risky sign-ins |
| Roles / least privilege | Give only the access needed for the job |
| Guest / external users | External access needs tighter review |

## What a junior might help with

- Reset / MFA help tickets (with correct process)
- Checking whether a user is in the right group
- Escalating risky sign-in alerts to senior staff
- Documenting identity hygiene (strong auth, no shared admin accounts)

## Related terms to know

- IAM (Identity and Access Management)
- SSO (Single Sign-On)
- Privileged access / admin roles
- Active Directory (on-prem) vs Entra ID (cloud) — often used together in hybrid setups
