# Microsoft 365 security basics

For entry-level cyber jobs, you do not need to be a full M365 admin — but you should know the main security areas names and what they do.

## Areas recruiters often mention

| Area | Junior-level understanding |
| --- | --- |
| Microsoft 365 | Email, collaboration, identity tied to Entra ID |
| Microsoft Defender | Threat protection signals for email, endpoints, identity |
| Intune / endpoint basics | Device compliance and basic device security policies |
| Data protection basics | Sensitivity labels / DLP concepts at a high level |
| Secure Score ideas | Organisation hygiene checklist (high level) |

## Typical junior tasks (examples)

- Triage a phishing / suspicious email report
- Check whether MFA is enabled for a user (with guidance)
- Follow a playbook for account lockout or unusual sign-in
- Log tickets clearly for escalation

## Link to IR and ATT&CK

Identity abuse (valid accounts, MFA fatigue, phishing) shows up often in real incidents. Pair these notes with the incident-response and MITRE ATT&CK lab repos.
